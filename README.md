# ASIC-Digital-System-Implementation
Multi-clock ASIC system processing UART command frames for Register File read/write and 14 ALU operations, returning results via UART TX. Integrates SYS_CTRL, RegFile, ALU, UART TX/RX, Clock Gating/Dividers, Pulse Generator, Reset/Data Synchronizers, and Async FIFO. Flow: Synthesis, Formality, DFT Scan Insertion, and Post-DFT Formality.
